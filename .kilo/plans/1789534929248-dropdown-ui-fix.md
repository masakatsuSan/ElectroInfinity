# Fix System-Default Dropdowns Across Website

## Context
The website has 30+ native `<select>` dropdowns that render with browser-default styling, which looks inconsistent and unprofessional. The Navbar dropdowns are already custom-styled. All other `<select>` elements need a unified, branded UI.

## Approach
Add global CSS in `frontend/src/index.css` to style ALL native `<select>` elements consistently with the design system (rounded-xl, hairline border, custom chevron arrow, proper focus/hover states). This single change fixes every dropdown site-wide without touching 15+ component files.

## Files to Modify
1. `frontend/src/index.css` — Add `<select>` styling in `@layer components` section

## CSS to Add (in `@layer components`)
- Base: white bg, hairline border, rounded-xl, padding matching `.input` class, Inter font, 14px/15px size
- Hover: darker border on hover
- Focus: border-primary + ring-1 ring-primary (matching `.input:focus`)
- Custom chevron: `appearance-none` + background SVG arrow (ChevronDown-style, slate color)
- `option` styling: white bg, proper padding, hover bg-soft-stone
- Disabled state: muted colors

## Validation
- Run `npm run dev` and visually verify dropdowns in:
  - Admin pages (Announcements, Resources, Calendar, Gallery, Achievements, Students, Deadlines, YT Lectures)
  - Public pages (Register, Gallery upload modal, Profile modals, Search filters, Forum create post, Calendar filter)
  - Faculty Dashboard
- Confirm custom arrow appears, focus ring works, hover states match design system
