# PWA Conversion Plan — Electro Infinity

Convert the React + Vite SPA into an installable PWA with disabled mobile zoom for a native app-like experience.

## Goals

1. **Installable** — users can add to home screen / install as app
2. **No zoom** — mobile users cannot pinch-zoom or double-tap zoom
3. **Offline support** — service worker caches app shell and assets
4. **App-like feel** — standalone display mode, theme colors, splash screen

## Files to Create/Modify

### 1. `frontend/public/manifest.json` — NEW

Web App Manifest for installability:

```json
{
  "name": "Electro Infinity",
  "short_name": "ElectroInf",
  "description": "Electro Infinity — Electrical Engineering Club, AGEMC",
  "start_url": "/",
  "display": "standalone",
  "background_color": "#0a0a0a",
  "theme_color": "#0a0a0a",
  "orientation": "portrait",
  "icons": [
    { "src": "/pic.png", "sizes": "192x192", "type": "image/png" },
    { "src": "/pic.png", "sizes": "512x512", "type": "image/png" },
    { "src": "/pic.png", "sizes": "512x512", "type": "image/png", "purpose": "maskable" }
  ]
}
```

### 2. `frontend/public/sw.js` — NEW

Service worker for offline caching. Strategy:
- **Precache** app shell (index.html, main JS/CSS chunks, pic.png) on install
- **Stale-while-revalidate** for API calls (network-first, cache fallback)
- **Cache-first** for static assets (JS, CSS, fonts, images)

### 3. `frontend/index.html` — MODIFY

Changes:
- Add `<link rel="manifest" href="/manifest.json" />`
- Add `<meta name="theme-color" content="#0a0a0a" />`
- Add Apple PWA tags:
  ```html
  <meta name="apple-mobile-web-app-capable" content="yes" />
  <meta name="apple-mobile-web-app-status-bar-style" content="black-translucent" />
  <meta name="apple-mobile-web-app-title" content="ElectroInf" />
  <link rel="apple-touch-icon" href="/pic.png" />
  ```
- **Disable zoom** by changing viewport to:
  ```html
  <meta name="viewport" content="width=device-width, initial-scale=1.0, maximum-scale=1.0, user-scalable=no, viewport-fit=cover" />
  ```
  Key additions: `maximum-scale=1.0` + `user-scalable=no`

### 4. `frontend/src/main.jsx` — MODIFY

Register service worker at the end of the file (after existing code):

```js
// Register service worker for PWA
if ('serviceWorker' in navigator) {
  window.addEventListener('load', () => {
    navigator.serviceWorker.register('/sw.js').catch(() => {
      // SW registration failed silently — app still works online
    });
  });
}
```

### 5. `frontend/src/index.css` — MODIFY (optional)

Add CSS to prevent text selection zoom and touch callouts for app-like feel:

```css
html, body {
  -webkit-touch-callout: none;
  -webkit-user-select: none;
  user-select: none;
  touch-action: manipulation;
}
```

Note: `touch-action: manipulation` eliminates 300ms tap delay and prevents double-tap zoom at the CSS level (complements the viewport meta tag).

## Implementation Order

1. Update `index.html` — viewport, manifest link, Apple PWA tags, theme-color
2. Create `public/manifest.json`
3. Create `public/sw.js` with caching strategies
4. Register SW in `main.jsx`
5. Add CSS touch/zoom prevention in `index.css`

## Validation

- Run `npm run build` in `frontend/` to ensure build passes
- Test in Chrome DevTools → Application tab → Manifest and Service Workers sections
- Test on mobile: attempt pinch-zoom (should be blocked), check "Add to Home Screen" prompt
- Verify standalone display mode works after installation

## Notes

- The `user-scalable=no` viewport setting may affect accessibility — users won't be able to zoom for readability. This is intentional per the requirement for a native app feel.
- The service worker should be designed to not interfere with the existing API proxy setup in `vite.config.js`.
- `pic.png` is used directly as the icon; for production quality, consider generating proper 192x192 and 512x512 PNG icons.
